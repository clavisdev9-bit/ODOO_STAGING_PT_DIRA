TMS Integration — Transport Management System for Odoo 18

Custom add-on untuk integrasi bi-directional antara TMS (FastAPI backend) dan Odoo 18. Dibangun untuk Retail Pengiriman Mainan dengan cakupan Jabodetabek & Bandung.

Fitur Utama

  • 7 Trigger Points otomatis (SO Confirmed → Invoice Created)
  • Custom fields pada stock.picking: TMS tracking, status, driver, vehicle, ETA, POD
  • Custom fields pada fleet.vehicle: kapasitas berat/volume, dimensi kargo, biaya operasional
  • Custom fields pada product: dimensi packaging untuk 3D capacity planning
  • Webhook endpoints: /tms/webhook/gps-update, delivery-complete, expense-create
  • Auto-validate picking & create invoice saat delivery complete (T6)
  • Auto-create hr.expense saat driver punch-out (T7)
  • Sync Log lengkap dengan audit trail untuk semua event TMS

Konfigurasi

Setelah install, set System Parameters berikut via Settings → Technical → System Parameters:

  • tms.backend.url — URL TMS FastAPI backend
  • tms.api.key — Bearer token untuk autentikasi ke TMS
  • tms.webhook.secret — Secret untuk validasi webhook dari TMS ke Odoo
  • tms.hmac.secret — HMAC secret untuk signature verification
  • tms.expense.product_id — Product ID untuk hr.expense otomatis
